## 3. 명령 규칙 (Windows CMD 기준)
- 코드·안내에서 명령은 **CMD 문법**으로 제시한다: `copy`(cp 아님), `\` 경로 구분, `%VAR%` 환경변수, `::` 주석. bash 전용 문법(`export`·`$VAR`·heredoc) 사용 금지.
- Supabase CLI는 전역 PATH에 없다. 반드시 `npx supabase ...` 형태로 호출한다.
- 반복 작업은 `scripts\*.bat`으로 스크립트화한다. 배치 파일은 `@echo off` + `call npm ...` 패턴.
- Python 보조 스크립트는 **소스 ASCII-only** 원칙(주석·문자열에 한글 직접 삽입 금지) — Windows CMD 인코딩 사고 방지.
- 파일 인코딩: 소스·문서 UTF-8. 한글 파일명 허용(문서·산출물), 코드 파일명은 영문.

## 4. 프로젝트 표준 명령 (package.json scripts)
| 명령 | 동작 |
|---|---|
| `npm run dev` | Next.js 개발 서버 (localhost:3000) |
| `npm run build` / `start` | 프로덕션 빌드/실행 |
| `npm run lint` / `test` | ESLint / vitest (lib/core 단위 테스트) |
| `npm run db:start` | 로컬 Supabase 기동 (Docker 필요) |
| `npm run db:reset` | migrations + seed.sql 재적용 (로컬 DB 초기화) |
| `npm run db:diff -- -f <이름>` | 스키마 변경 → 마이그레이션 파일 생성 |
| `npm run db:types` | `types/database.ts` 타입 재생성 |

## 6. 환경변수 (.env.local — 커밋 금지)
| 변수 | 범위 | 비고 |
|---|---|---|
| NEXT_PUBLIC_SUPABASE_URL | 클라이언트 허용 | 로컬 http://127.0.0.1:54321 |
| NEXT_PUBLIC_SUPABASE_ANON_KEY | 클라이언트 허용 | 신형 키 형식 `sb_publishable_...` |
| SUPABASE_SERVICE_ROLE_KEY | **서버 전용** | 신형 키 형식 `sb_secret_...` |
| ANTHROPIC_API_KEY / AI_MODEL | **서버 전용** | 클라이언트 번들 유입 금지 |
| TOSS_CLIENT_KEY / TOSS_SECRET_KEY | 클라이언트/서버 | R2 단계에서 발급 |
| NEXT_PUBLIC_APP_URL | 공통 | 로컬 http://localhost:3000 |

환경 3단: local(도커) → staging(Supabase 프로젝트 A + Vercel Preview) → production(프로젝트 B + Vercel Production). 스테이징·프로덕션 키는 Vercel 환경변수로만 관리.

## 7. 코드 배치 규칙 (상세는 05·CLAUDE.md)
- 도메인 로직(검출 룰·위약금 엔진·가격 계산·zod 스키마)은 `lib/core/` — React/Next import 금지.
- Claude API 호출은 `app/api/**` 서버에서만, 클라이언트 직접 호출 금지.
- DB 스키마는 `supabase/migrations/` 단일 진실. 대시보드 수동 변경 금지.
- 개인정보: 계약서 원문은 분석 후 즉시 파기, 마스킹 후 AI 전달, 로그에 원문·경로 금지. 테스트 샘플은 `_local_reports\samples\`(git 제외).

## 8. 일상 개발 사이클
1. `dev`에서 기능 브랜치 생성 → 작업. 브랜치명 규약: `feat|fix|chore/<태스크ID>-<요약>` (예: `feat/T-03-migrations`)
2. DB 변경 시: 로컬 수정 → `npm run db:diff -- -f 변경명` → 마이그레이션 커밋 → `npm run db:types`.
3. 커밋 전: `npm run lint && npm run test`.
4. PR → dev 병합 → main 배포. **main 직접 push는 GitHub ruleset(main-protection)으로 차단됨.**
5. 새 의사결정 발생 시 04_의사결정로그.md에 D-번호로 추가.

## 10. Claude(AI)와의 협업 방식
- **클로드 프로젝트(웹)**: 기획·문서·전략 작업, Claude Code용 프롬프트 작성.
