# 01. 사업 개요 컨텍스트 — 웨딩클리어(WeddingClear)

> 사업기획서 v1(2026.8)의 핵심 요약. 상세 수치 근거는 02_시장데이터.md 참조.

## 정의
- **한 줄 정의**: 예비부부가 플래너·컨설팅사를 거치지 않고, 공개된 정찰 가격으로 웨딩홀·스드메를 비교·예약·계약·결제까지 끝내는 직거래 플랫폼. AI 플래너가 준비 전 과정을 조율한다.
- **형태**: 양면 마켓플레이스(소비자↔결혼서비스 공급자) + AI 에이전트.
- **비전**: 결혼 준비의 모든 가격이 투명하고 모든 거래가 안전한 시장 — 웨딩 거래의 표준 인프라.

## 목적 4가지
1. **정보 비대칭 해소**: 가격 공개율 36.1%(스드메 참가격 공개율 3.7%) 시장에 정찰 유통 채널 구축.
2. **유통 마진 재편**: 컨설팅 리베이트 ~30% → 플랫폼 수수료 5~8%. 차액을 소비자 가격 인하·업체 수익 개선으로.
3. **준비 노동 자동화**: 소비자가 플래너를 쓰는 이유는 정보가 아니라 '귀찮음+실패 공포'. AI가 일정·예산·업체 커뮤니케이션·리스크 관리를 대행.
4. **거래 신뢰 제도화**: 표준 전자계약+에스크로+실계약 검증 후기로 "이 플랫폼에서 계약하면 안전하다"를 구조화.

## Why Now (5 동인)
- **규제**: 2025.11 가격표시 의무화(과태료 최대 1억), 표준약관 제정(2025.3), 결혼서비스법 추진, 공정위 집중점검(2026.8~).
- **수요**: 혼인 3년 연속 증가(2025년 24만 건, +8.1%), 웨딩플레이션으로 가격 민감도 정점.
- **공급**: 예식장 21.1% 감소(951→750곳)로 성수기 예약난 / 비수기·평일·지방은 공실 — 비대칭.
- **기술**: LLM 에이전트 실용화(웨딩북 AI 상담→예약 전환 20~25% 실증).
- **기존 질서 균열**: 공정위 대행업체 10곳 제재, 리베이트 공론화, 컨설팅·박람회 불신 확산.

## 서비스 기능 (3면)
### 소비자
- **AI 플래너 '클리어'**: 온보딩 플랜 생성(D-day 타임라인·예산 배분) → 대화형 상품 탐색(실지불 총액 기준 비교) → 일정·커뮤니케이션 조율(투어 예약 대행, 업체 질의 대리) → 예산 자동 추적 → 리스크 감시(계약 주의점 브리핑) → 휴먼 백업(케어 매니저/독립 플래너).
- **투명 가격 탐색**: 입점 조건=가격 전면 공개, '실지불 총액'(필수옵션 포함) 표기 의무, 실시간 재고 캘린더(비수기·잔여타임 할인 자동 표시), 시세 분포·내 견적 백분위.
- **안전 거래**: 표준약관 기반 전자계약, 에스크로(계약금→중도금→이행 확인 후 잔금), AI 계약서 검토(외부 계약도 업로드 검토 — 유입 무기), 위약금 계산기·분쟁 지원(1372 연계).
- **유틸리티(리텐션)**: 모바일 청첩장·RSVP·축의금 정산·하객 관리·커플 계정.

### 공급자(업체)
- 컴플라이언스 대행(가격표시 의무 자동화 — "입점=규제 준수"), 재고·다이내믹 프라이싱(호텔 RMS 방식), 예약·정산 대시보드, 수요 데이터 리포트. **유료 순위 광고 없음** — 검색 순위는 가격·후기·이행 데이터로만.

### 플래너
- 독립 플래너 마켓: 검증 프로필(진행 건수·전문·평점), 리베이트 프리 보수(고객 지불 컨설팅비+매칭 수수료), '업체 리베이트 0원' 인증 배지, 선택형 결합(전체/부분/당일).

## 차별성 3중 구조
1. **구조적(수익 모델)**: 기존 전 사업자(웨딩북·메링·컨설팅)는 업체로부터 돈을 받으므로 가격 정찰 강제·소비자 측 검증·추가금 데이터 공개가 불가(이해상충). 우리는 거래 수수료+소비자 멤버십 구조라 가능 — 기능 카피가 아닌 사업 모델 전환이 필요해 방어 기간이 길다.
2. **제품적(AI 에이전트)**: 경쟁 AI는 '검색 챗'. 우리는 계약·결제·일정 데이터가 플랫폼 안에 있어 실행형 에이전트(예약 대행·충돌 감지·지출 추적)가 됨.
3. **데이터(신뢰 자산)**: 실계약 기반 추가금 발생률·위약금 분쟁률·이행 데이터는 거래에서만 축적 — 조작 불가 평판 지표가 축적형 해자.

## 수익 모델
| 수익원 | 요율/가격(안) | 시점 |
|---|---|---|
| 거래 수수료(주력, 업체 부담) | 5~8% | P1~ |
| 소비자 멤버십(AI 고급 기능) | 커플당 49,000~99,000원 | P1~ |
| 컴플라이언스 SaaS(비입점 업체) | 월 5~15만 원 | P2 |
| 플래너 매칭 수수료 | 10% 내외 | P3 |
| 금융·보험 제휴, 데이터 리포트 | 제휴/구독 | P3~P4 |

단위 경제(가정): 계약 단가 500만 × 6% = 건당 30만, 커플당 2.5건 → 커플당 ~75만 + 멤버십. CAC 5~10만 가정 시 LTV/CAC 7배+.

## 진입 전략 (콜드스타트 4단계)
1. **P1 수요 선확보(0~12M)**: 공급 없이 완결되는 기능(AI 플랜·계약 검토·위약금 계산·시세 비교)으로 커플 확보. Gate: MAU 커플 2만, 멤버십 전환 5%, 월 리텐션 40%.
2. **P2 절박한 공급(9~21M)**: 비수기·평일 재고 스튜디오/홀(페이백 관행=지불의사 입증), 신규·지방. 영업 대상=매출 KPI의 실장. Gate: 입점 100곳, 월 거래 300건, 재계약 70%.
3. **P3 거래 표준(18~36M)**: 전자계약·에스크로 전면화, 검증 후기·평판 지표 공개(연 5천 건 임계), 플래너 마켓. 네트워크 효과 국면.
4. **P4 확장(30M~)**: 혼수·허니문·금융·데이터. SOM(거래액 연 1,000억) 도달.

## 재무·투자 (요약)
- 3개년: GMV 20억→150억→400억 / 매출 3억→13억→32억 / 4차년 흑자 전환 목표.
- 시드 10~15억: 개발·AI 40%, 팀 30%, 마케팅 20%, 법무·운영 10%. 18개월 내 P1 Gate + P2 진입.
- 조직: 시드 5~7명(대표, 풀스택 2, AI 1, 도메인·콘텐츠 1, CS 1) → Pre-A 12~15명(공급 영업 3 포함).

## 핵심 리스크
소개망 보복(초기 공급 세그먼트 한정으로 회피) / 콜드스타트(P1 단독 생존 설계) / 웨딩북 방어(거래 레이어 선점으로 회피) / 에스크로 규제(초기 PG 에스크로 활용→추후 라이선스) / AI 법적 책임(참고 정보 고지+인용 검증+보험).
